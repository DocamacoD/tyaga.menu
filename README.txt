СТАРТОВЫЙ ШАБЛОН МОБИЛЬНОГО МЕНЮ

Состав:
- index.html — структура страницы и пример блюд
- styles.css — внешний вид, адаптация под мобильные устройства
- script.js — фильтр по категориям и автоматический год в подвале

Как запустить:
1. Распакуйте папку.
2. Откройте папку в Visual Studio Code.
3. Установите расширение Live Server (Extensions / Расширения).
4. Нажмите правой кнопкой по index.html → Open with Live Server.
5. Для проверки на телефоне откройте адрес локального сервера, используя IP компьютера
   в той же Wi-Fi сети. Для публичного доступа сайт нужно разместить на хостинге.

Как наполнить:
- В index.html замените название «ТЯГА», описание, телефон, названия блюд, состав и цены.
- Каждый товар — блок article.product-card или div.menu-row.
- Для фильтрации используйте data-category="food", "drinks" или "dessert".
- Фото пока представлены цветными заглушками. Позже замените div.product-image на:
  <img class="dish-photo" src="images/burger.jpg" alt="Фирменный бургер">
  и добавьте в styles.css:
  .dish-photo { width:100%; height:100%; object-fit:cover; border-radius:9px; }
  Лучше разместить изображения в папке images.

Как сделать QR-код:
1. Сначала разместите сайт на публичном хостинге, чтобы у него появился постоянный HTTPS-адрес.
2. Создайте QR-код, который ведёт именно на этот адрес.
3. Проверьте его камерой нескольких телефонов до печати.
QR-код, ведущий на localhost или локальный адрес компьютера, гостям не подойдёт.

Важно:
- Это статический шаблон, корзины и онлайн-заказа в нём нет.
- Для меню, которое можно менять без редактирования HTML, позже можно подключить CMS или базу данных.
